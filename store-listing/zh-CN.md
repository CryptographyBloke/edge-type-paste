# Microsoft Edge Add-ons 中文商店文案

## 名称

逐字输入

## Description

逐字输入是一款浏览器侧边栏文字输入工具。将文字键入或粘贴到侧边栏，点击“等待选择网页输入框”，再点击网页中的目标输入位置；如果已经选中输入框，也可以直接启动输入。侧边栏会保持打开，方便在文字和网页之间切换。

扩展会把文字逐字符输入到用户选定的单行、多行文本框或常见可编辑区域，支持中文、英文、数字和常用符号。每字符间隔可设置为 0–500 毫秒，默认值为 0。对于 Monaco、CodeMirror、Ace 等编辑器，扩展会尝试处理自动缩进，减少行首空格重复。

扩展不调用网页的粘贴操作，适用于粘贴受限但仍允许键盘输入的场景。草稿仅暂存在当前浏览器会话；扩展不调用剪贴板读取接口、不上传文字，也不会自动提交网页表单。输入完成后请检查网页中的内容。浏览器内部页面、Edge Add-ons 商店页面，以及禁止键盘输入或使用特殊校验的页面可能无法使用。请遵守目标网站的使用规则。

## Privacy 表单

### Single purpose description

本扩展将用户主动输入或粘贴到侧边栏的文本，逐字符输入到用户在当前网页中选定的可编辑字段。用户可以设置字符间隔。为定位输入框，扩展会在网页中监听编辑字段的焦点变化；只有用户启动输入并选择目标后，才会向该字段发送输入内容。对于禁用粘贴、但仍允许键盘输入的网页，扩展通过逐字符输入文字，而非调用网页的粘贴功能。扩展不会自动提交表单，也不会向开发者或第三方服务器发送文本。请遵守目标网站的使用规则。

### storage justification

storage.session 用于在当前浏览器会话中暂存侧边栏草稿，以及用户当前选中的标签页、框架和输入框标识，以便开始输入时找到对应目标。草稿可通过侧边栏的“清空侧边栏文字”按钮删除；目标标识会在标签页关闭或导航时清理。扩展不通过网络发送这些数据。

### tabs justification

用于识别当前活动标签页，在用户启动输入时向对应网页发送目标选择和输入请求，并在输入期间切换回该标签页。标签页关闭或导航时，扩展也会清理对应的临时目标标识。当前实现不读取浏览历史。

### debugger justification

用于在用户启动逐字输入时，临时连接当前选中的网页标签页，并通过 Input.dispatchKeyEvent 和 Input.insertText 发送逐字符输入事件。输入完成或失败后，扩展立即断开连接。当前实现仅将此接口用于向用户选定的输入框发送文字。

### sidePanel justification

用于显示扩展侧边栏，让用户输入或粘贴文字、设置字符间隔并启动输入。浏览器原生侧边栏在用户转到网页选择目标输入框时仍保持打开。

### scripting justification

用户点击“等待选择网页输入框”或“输入到已选输入框”时，扩展使用 scripting 将随扩展安装的本地内容脚本注入当前标签页及其框架。脚本用于识别用户聚焦的可编辑字段、记录光标或选区，并在输入前恢复目标位置。扩展不加载远程脚本。

### Host permission justification

`<all_urls>` 用于让内容脚本在用户可能选择的网页和嵌入式框架中识别焦点所在的可编辑字段。目标网站无法预先限定；脚本会监听输入字段的焦点和光标变化，以定位用户选定的目标。扩展不会遍历或上传网页文本，也不会向外部服务器发送网页内容。
