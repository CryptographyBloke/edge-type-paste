# 逐字输入

一个 Microsoft Edge Manifest V3 扩展。用户把文字放入侧边栏、选中网页输入框后，扩展通过浏览器输入接口逐字符发送文字。它不调用目标网页的粘贴操作，适用于粘贴受限、但仍允许键盘输入且网站规则允许的场景。

## 功能

- 使用 Edge 原生侧边栏，切换到网页选择输入框时侧栏保持打开。
- 支持在侧栏中键入文字，或由用户使用浏览器粘贴到侧栏。
- 支持单行、多行文本框和常见可编辑区域，以及中文、英文、数字和 Unicode 字符。
- 每字符间隔可设置为 0–500 毫秒，默认 0 毫秒。
- 尝试兼容 Monaco、CodeMirror、Ace 等编辑器的自动缩进，减少重复行首空格。
- 文本草稿保存在当前浏览器会话中；用户可以在侧栏清空。

## 在 Edge 中本地安装

1. 打开 `edge://extensions` 并启用“开发人员模式”。
2. 选择“加载解压缩的扩展”，选中本项目根目录（包含 `manifest.json` 的目录）。
3. 固定“逐字输入”扩展图标，打开侧边栏。
4. 在侧栏中放入文本，点击“等待选择网页输入框”，再点击网页中的目标位置。若已选中目标，也可点击“输入到已选输入框”。
5. 检查输入结果，再由用户决定是否提交网页表单。

浏览器可能在逐字输入时提示扩展正在调试该标签页。这是 `debugger` 权限用于发送输入事件时的浏览器提示；扩展会在输入完成或失败后断开连接。

## 权限用途

- `storage`：在本地会话存储侧边栏草稿和所选目标标识。
- `tabs`：定位当前活动标签页、把输入请求发送到该标签页，并清理已关闭或导航的标签页状态。
- `debugger`：通过 `Input.dispatchKeyEvent` 和 `Input.insertText` 向用户选定的网页输入框发送字符。
- `sidePanel`：显示保持打开的输入侧栏。
- `scripting`：在用户启动功能时向当前标签页注入随扩展打包的内容脚本。
- `<all_urls>`：让内容脚本在用户可能选择的网页及其框架中识别焦点输入框。内容脚本会监听焦点和光标变化，并只检查目标附近的状态以兼容缩进。

## 数据处理与限制

扩展不调用系统剪贴板读取接口、不把文本发送到外部服务器，也不会自动提交表单。侧栏草稿使用 `chrome.storage.session` 暂存；用户清空草稿后，文本从会话存储删除。目标网站、编辑器和浏览器内置页面可能有不同限制，某些页面无法使用。请遵守目标网站的使用规则，并在提交前核对内容。
